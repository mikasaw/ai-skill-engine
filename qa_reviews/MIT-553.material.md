## 背景
mdboard 把一个目录下的 Markdown 任务文件渲染成静态 HTML 看板。纯 Python 标准库（3.10+），
禁止任何第三方运行时依赖；测试框架用 pytest。

## 功能范围（三阶段）
1. **front-matter 解析**：解析 `--- ... ---` 块内的 `title` / `status` / `tags` 字段；
   `status` 仅接受 todo/doing/done，缺省 todo；非 Markdown 文件跳过；front-matter 格式错误抛带原因的异常。
2. **HTML 看板生成**：按状态三列渲染，输出单文件 `index.html`；
   所有插值文本必须 HTML 转义（含 `<script>` 的内容不得原样出现在输出中）。
3. **增量重建**：持久化每个源文件的 mtime+size 快照；无变更时二次运行零重解析；
   单文件变更仅影响其自身渲染产物。
