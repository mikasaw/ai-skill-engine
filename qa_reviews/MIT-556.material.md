## S2 交付物：`mdboard/render.py` + `tests/test_html.py`

### 数据契约

```python
def render_card(task: Task) -> str            # 单任务卡片片段，无外层包装
def render_page(tasks: Iterable[Task]) -> str # 完整单文件页面
def write_page(tasks: Iterable[Task], out_path: str | Path) -> Path
```

### 结构契约

- 输出**单文件** `index.html`，CSS 内联，不引用任何外部资源，**模板自身不含任何 `<script>` 标签**。
- `head` 内含字面量 `<title>mdboard</title>`。
- 三个列容器**恒定存在**（即使该列无任务）：`data-status="todo"`、`data-status="doing"`、`data-status="done"`，形如 `<section class="column" data-status="todo">`。
- 卡片片段：`<article class="card">` 内含 `<h3>` 标题文本 + `<ul class="tags">` 标签项。`render_card` 的返回值就是 S3 要缓存的"自身渲染产物"，因此**不得**在片段内写入整页内容。
- **列内顺序确定性**：先按 `status` 分列，列内按 `source.replace("\\", "/")` 字典序升序。同一输入必须产出逐字节相同的输出（S3 依赖这一点）。

### 转义红线（本阶段唯一不可协商项）

1. 所有插值文本（标题、标签、`source` 等任何来自 .md 的内容）一律经 `html.escape(text, quote=True)`，且只在**文本节点**出现。
2. **禁止**把任何插值文本写进 HTML 属性；属性只允许模板里的固定字面量。
3. 禁止用字符串拼接绕过转义（例如先拼 `<h3>` 再整体 escape）。
4. 验收断言（评审方复跑）：任务标题为 `<script>alert(1)</script>` 时，生成的 HTML 中 `"<script>" not in out` **成立**，且 `"&lt;script&gt;" in out` 成立。
5. 同样覆盖 `&`、`"`、`'`、`<img onerror=...>` 混入标签的用例。

### 验收判据（评审方逐条复跑）

- `python -m pytest tests/test_html.py -q` 全绿。
- 断言含：`<title>mdboard</title>`；三个 `data-status="todo|doing|done"` 容器；`<script>` 输入被转义（见上第 4 条）；空目录仍生成三列。
- 断言确定性：同输入两次 `render_page` 结果相等。
- `python -m pytest -q` 全绿（S1 用例不得回归）；无第三方 import。
